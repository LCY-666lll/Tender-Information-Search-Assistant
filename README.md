# 招投标信息聚合工具

赛题 1 工程：多网站招投标信息搜索、聚合、清洗、去重和 Word 展示。

## 功能

- 自然语言解析：关键词、地区、时间范围、频率。
- 多来源聚合：官方公共资源、政府采购、招投标专业源、省级平台、企业采购门户、登录态来源预留。
- 来源降级：单个网站失败只记录 warning，不影响报告生成。
- 字段抽取：标题、发布时间、来源链接、核心内容、附件链接。
- 清洗去重：关键词/地区/时间过滤，标题日期和正文摘要去重，多源链接合并。
- 风险预警：截止时间临近、附件缺失、未识别截止时间、变更/澄清公告。
- Word 输出：包含查询条件、来源覆盖概览、风险概览、公告明细和去重说明。
- 本地增量：`data/history/*.json` 记录已输出 item，重复任务不重复推送旧公告。
