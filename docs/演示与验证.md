# 演示与验证

## 演示主线

1. 启动系统并访问 `http://localhost:8081/`。
2. 输入：`最近1个月上海充电桩招标信息有哪些`。
3. 查看解析结果：关键词、地区、时间、频率。
4. 查看多来源覆盖状态：成功数、失败 warning、耗时。
5. 下载 Word 报告。
6. 打开 Word，展示来源覆盖概览、公告明细、风险预警和去重说明。

## 验证命令

```powershell
cd D:\xfusion-hackathon\problems\p2\work\bid-aggregator
mvn test
mvn spring-boot:run
```

## 评分点映射

- 自然语言解析：页面解析结果 + `IntentParserTest`。
- 多网站抓取：页面来源状态表 + Word 来源覆盖概览。
- 字段抽取：Word 公告明细。
- 清洗去重：Word 去重说明 + 本地 history。
- 风险预警：页面公告预览 + Word 风险概览。
- 用户体验：Web 输入、报告下载。
- 工程质量：统一 `SourceCrawler` 接口和分层服务。
